# The Zootric System

A public, sanitized snapshot of the agent system behind [Zootric](https://zootric.com) —
a growth studio that builds AI systems, brands, web, and digital growth as one connected practice.

It shows the **skills, specialist agents, and commands** the studio runs on top of
[Claude Code](https://claude.com/claude-code), with engineering discipline
(brainstorm → plan → test → verify) wired into every build.

**Live:** https://claude-config-zootric.vercel.app

### What this is
- A searchable showcase of our workflow and tooling.
- Generated directly from the system itself, so it stays honest.
- Third-party skills (tagged `ext`) are open-source and credited to their authors.

### What this is not
- No client names, client work, or private repositories.
- No internal operations, pricing, credentials, or infrastructure.

Single static page — `index.html`. Nothing to build.
